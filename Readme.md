How to Run the Project

Create the project folder structure as mentioned above

Copy each file into its respective folder (HTML, CSS, JS, assets)

Open index.html in any modern web browser

The portfolio will load automatically with all animations and interactions enabled

No setup, build tools, or frameworks are required.

Key Features Implemented

✅ Entry Animation
Soft firecracker/confetti animation with a welcoming text when the website loads, creating a strong first impression.

✅ Side Menu Navigation
A clean, icon-based side menu with smooth open/close animations and section highlighting on scroll.

✅ Custom Cursor Interaction
An interactive cursor that responds to hover and movement, enhancing the overall user experience.

✅ Parallax & Mouse Effects
Subtle parallax effects on text, images, and sections based on mouse movement for a modern feel.

✅ Hero Image Gallery
A dynamic hero section with 6–7 images that move slightly with mouse motion to create depth and engagement.

✅ Skills Section
Card-based layout showcasing technical skills with logos and clean descriptions, easy to update in the future.

✅ Future Scope Section
Dedicated cards highlighting areas I’m interested in learning further, such as:

System Design

Cloud Computing

Generative AI

React JS

Backend Architecture

✅ Dashboard Section
A mini dashboard featuring animated counters (including follower count animation from 0 to 262) and progress indicators.

✅ Mini Game
A lightweight reaction-based mini game added for engagement, without affecting performance.

✅ Image Gallery Section
A separate gallery section where images can be added easily, featuring hover zoom and subtle motion effects.

✅ Fully Responsive Design
Mobile-first layout that adapts smoothly across phones, tablets, and desktops.

✅ Dark Modern Theme
A premium dark UI with carefully chosen accent colors and proper spacing.

✅ Human-Centered Content
All text is written in a natural, honest tone — beginner-friendly and learning-focused, not exaggerated or AI-like.
